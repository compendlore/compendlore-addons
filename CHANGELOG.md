# Changelog

All notable changes to the official Compendlore addons are recorded in this file. Entries remain
under `Unreleased` until the release manager assigns a version and publication date.

## [Unreleased]

### Added

- Established the official-addon monorepo foundation, package workspace, TypeScript 6 build, and
  repository quality checks.
- Added the official addon catalogue and reusable addon template foundations.
- Added a Docker quality image for reproducible addon validation.
- Added automated dependency maintenance for npm and GitHub Actions.

### Changed

- Normalized repository line endings and dependency-lock resolution.
- Internal architecture, planning, governance, and audit documents are maintained in the workspace
  documentation tree instead of this repository.
- Repository Markdown is limited to useful operational files, written in English first and French
  second; this changelog remains English-only.

### Fixed

- Overrode the vulnerable transitive KaTeX version.

### Release notes

- No official addon version has been released yet.
